# VetSystem

Sistema web para gerenciamento de animais em uma clínica veterinária.

## Objetivo

O VetSystem tem como objetivo organizar informações dos animais atendidos pela clínica, permitindo o cadastro e a visualização de dados como espécie, raça, idade, tutor, histórico vacinal e prontuário.

## Funcionalidades previstas

- Cadastro de animais
- Listagem de animais cadastrados
- Visualização dos detalhes do animal
- Pesquisa de animais
- Filtro por espécie
- Ordenação dos animais
- Edição de informações
- Exclusão de animais
- Informações da clínica
- Localização da clínica e serviços veterinários próximos por meio do Google Maps

## Tecnologias

- HTML
- CSS
- JavaScript
