# VetSystem

Sistema web para gerenciamento de animais em uma clínica veterinária.

## Objetivo

O VetSystem tem como objetivo organizar as informações dos animais atendidos por uma clínica veterinária, permitindo o cadastro e o gerenciamento de dados como nome, espécie, raça, idade, tutor, histórico vacinal e prontuário.

## Funcionalidades

- Cadastro de animais
- Listagem dinâmica de animais
- Visualização dos detalhes dos animais
- Edição de informações
- Exclusão de animais
- Pesquisa por nome ou tutor
- Filtro por espécie
- Ordenação por nome ou idade
- Validação dos campos obrigatórios
- Mensagens de confirmação das operações
- Informações da clínica

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git e GitHub
- GitHub Pages

## Desenvolvimento

O projeto está sendo desenvolvido em três etapas:

**Etapa 1 — HTML:** criação da estrutura inicial da aplicação, incluindo formulários, listagem e navegação.

**Etapa 2 — CSS:** implementação da identidade visual, estilização dos componentes, Flexbox, CSS Grid e responsividade.

**Etapa 3 — JavaScript:** implementação das funcionalidades de cadastro, listagem, edição, exclusão, pesquisa, filtros e ordenação.
